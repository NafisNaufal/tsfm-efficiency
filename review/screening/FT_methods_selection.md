# Selection process - full-text assessment

Of 361 reports sought for retrieval, 112 could not be retrieved. 249 full-text reports were assessed independently by two AI reviewers (both Claude Sonnet 5.5 (claude-sonnet-5-5), prompted with different expert personas) using the sr-screener skill (version 1.0.0) of the open-source Academic Research Skills suite (https://github.com/Imbad0202/academic-research-skills), running in Claude Code; each reviewer recorded one exclusion reason and the page supporting it. The reviewer agents had read-only file tools and no web access; each was instructed to read only the file it was given. Disagreements were resolved by a third AI reviewer (Claude Opus 5.5 (claude-opus-5-5)). The reviewers agreed on include-versus-exclude decisions for 96.0% of reports (Cohen's kappa = 0.906). 75 reports were excluded (E1 Publication type (editorial, comment, erratum, front matter, call for papers, dataset-only) (n = 8); E2 Not about forecasting/filtering/predicting time series or dynamical systems (n = 11); E3 No pretrained foundation model and no in-context transformer forecaster (n = 20); E4 None of oracle / classical / naive-on-unpredictable / context-length / mechanism analysis (n = 36)); 0 await classification; 174 reports met the eligibility criteria.
